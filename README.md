# Planner: van nieuw stucwerk naar schilderwerk

Een kleine, statische planner in één HTML-bestand. Je vult de opleverdatum van het stucwerk, de droogtijd volgens de stukadoor of fabrikant, een marge en het aantal verflagen in. De planner zet de vroegste data voor elke stap op een rij.

Live: https://schilderkosten.github.io/

- Geen vaste droogtijd ingebakken: de gebruiker vult het advies van de vakman of het productblad in.
- Geen tracking, geen externe scripts.

Achtergrond over prijzen: [Stukadoor-kosten.nl](https://stukadoor-kosten.nl/) en [schilderwerk op nieuw stucwerk](https://schilder-kosten.nl/nieuw-stucwerk-schilderen/).

Gemaakt door de redactie van Cost Guide Nederland, verbonden aan SkilledContractors, met hulp van AI.
